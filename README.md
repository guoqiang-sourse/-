# 岱宗盒子（社区魔改版）

> 本项目是基于 [yeliqin666/xjtu-toolbox-android](https://github.com/yeliqin666/xjtu-toolbox-android) 开展的社区二次开发（魔改）版本。
>
> 它不是原项目的官方版本，也没有得到原作者的官方背书。本项目与原作者不存在隶属或代理关系，原始版权仍归原作者及贡献者所有。

## 为什么要做这个版本

我们认可原版岱宗盒子在西安交通大学校园服务整合上的价值，也感谢原作者和贡献者公开源码、持续维护，为后来者提供了学习和改进的基础。

这份魔改版秉承开源精神，在尊重原项目版权、名称和贡献记录的前提下，针对新版学校接口、日常使用体验和发布方式做进一步适配与优化。修改范围尽量保持透明，避免与原版官方发布混淆；如果原作者对二次发布、署名方式或功能改动有异议，可以通过仓库 Issue 联系，我们会及时调整或停止相关分发。

## 与原版的主要区别

| 方向 | 原版岱宗盒子 | 本社区魔改版 |
|------|--------------|--------------|
| 版本定位 | 原作者官方维护版本 | 基于原版公开源码进一步优化、适配和修复的社区版本 |
| 更新渠道 | 使用原项目发布渠道与更新来源 | 改为本应用独立的软件内更新清单，不与原项目更新渠道混用 |
| 更新说明 | 原项目发布说明 | 使用本项目独立更新日志，并明确标注与原版的关系 |
| 底栏结构 | 包含“学辅”等一级入口 | 移除“学辅”一级入口，底栏精简为首页、日程、屁岱、我的四项 |
| 屁岱入口 | 既有导航与主动提醒逻辑 | 统一首页和底栏的屁岱导航路径，隔离气泡、持久化与页面切换，修复闪退 |
| 考勤与请假 | 原版考勤能力 | 适配新版考勤系统，增加病假、私事假、请假记录、审批进度、附件、撤回和销假等能力 |
| 日程定位 | 按原版周次计算逻辑 | 按 2026-2027 学年校历校正开学时间，2026 年 9 月 14 日开学，开学前不再提前显示第一周课程 |
| 校历 | 依赖原校历数据 | 内置西安交通大学教务处发布的 2026-2027 学年校历，接口为空或失败时仍可离线展示 |
| 桌面小部件 | 原版 2×2 / 4×2 小部件 | 重排 4×2 小部件，压缩无效信息，优先让一天的日程无需上下翻动即可看完 |
| 教材下载 | 原版教材全文阅读体验 | 逐页提取服务端原图并合成为 PDF，保存到 `Download/XJTUToolBox/` 并登记到应用下载管理 |
| 设置与发布 | 保留原项目主页、致谢和反馈入口 | 精简应用设置页；完整来源、致谢和版权说明集中保留在 README 与 Release 说明中 |

除上述改动外，大部分基础功能、校园接口适配思路、界面结构和项目名称均继承自上游项目。本版不会以二次修改为由改变上游代码、名称、文档或贡献者的版权归属。
